# nobel_laureates
Нобелевские лауреаты 1901-2022
Проверил, выросла ли доля лауреатов из США после 1945 года. Ещё сделал несколько запросов на SQL к этим же данным.
Данные с Kaggle: Nobel Laureates - From 1901 To 2022. Файлы лежат в репозитории.
Чтобы запустить: положить файлы csv рядом с файлом Nobel_analysis.ipynb и запустить все ячейки.
